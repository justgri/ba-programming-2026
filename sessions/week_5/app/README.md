# Lecture 5 Streamlit app

Run from the repository root:

```sh
python3 -m pip install -r sessions/week_5/app/requirements.txt
python3 -m streamlit run sessions/week_5/app/app.py
```

Pages live in `pages/` and are registered in `app.py`. Data paths are relative to
the app's location, so it can also be launched from this directory.
